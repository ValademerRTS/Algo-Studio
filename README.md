# Algo Studio


Расширение для Visual Studio Code, предназначенное для каталогизации, быстрого поиска и вставки алгоритмических шаблонов в исходный код.

---

## Основные возможности

### 1. Интеллектуальное автодополнение (Snippets)
- Поддержка языков: C++, C, Python
- Вставка сниппетов через стандартное меню подсказок редактора при вводе названия алгоритма
- Отображение асимптотической сложности и описания в окне документации подсказки

### 2. Панель управления (Webview GUI)
- Создание, редактирование и удаление собственных алгоритмических реализаций
- Привязка иллюстраций и блок-схем к алгоритмам (с автоматической конвертацией в Base64)
- Копирование кода в системный буфер обмена в один клик
- Сброс базы к предустановленным значениям

### 3. Поиск и фильтрация
- Мгновенный поиск без перезагрузки интерфейса по названию, сложности, категории или описанию и языку

### 4. Данные
- Хранение всех данных в системном хранилище `context.globalState`

## Быстрый старт

### Требования
- Visual Studio Code версии 1.75.0 или выше
- Node.js версии 16.x или выше (для разработки и сборки)

### Запуск в режиме отладки
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/ValademerRTS/Algo-Studio.git
   cd algo-studio
   
2. Откройте проект в VS Code:

    ```Bash
    code .
    ```

3. Нажмите F5 для запуска нового окна VS Code (Extension Development Host) с активированным расширением

* команда - algoHelper.openManager — открыть графическую панель управления алгоритмами. Команда вызывается через палитру команд(Ctrl+Shift+P)
