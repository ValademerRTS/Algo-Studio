# Algo Studio 🚀

**Algo Studio** — это расширение-шпаргалка для Visual Studio Code. Оно позволяет хранить коллекцию алгоритмов, быстро искать нужные решения, вставлять готовый код прямо в файл через автодополнение и подтягивать шаблоны с сервера.

---

## Что умеет расширение

1. **50 готовых алгоритмов «из коробки»**  
   База уже содержит 50 популярных задач и шаблонов на **Python**, **JavaScript** и **C++**: сортировки, графы (Dijkstra, BFS, DFS), математика (НОД, решето Эратосфена), структуры данных (стек, очередь, DSU) и геометрия.

2. **Быстрая вставка кода (Сниппеты)**  
   В файлах `.py`, `.js`, `.cpp` или `.c` начните вводить название алгоритма (например, `Binary Search` или `quickSort`). VS Code покажет подсказку со сложностью $O(...)$ и описанием. Нажмите `Enter` или `Tab` — код вставится в редактор.

3. **Удобная визуальная панель**  
   - Просмотр кода с красивой подсветкой синтаксиса.
   - Копирование любого алгоритма в буфер обмена за один клик.
   - Фильтр по языкам (C++, Python, JS, Все) и живой поиск по названию/сложности/категории.
   - Добавление своих алгоритмов с возможностью прикрепить картинку или блок-схему (сохраняется в Base64).
   - Редактирование и удаление существующих записей.

4. **Синхронизация с сервером**  
   - Кнопка **«Скачать с сервера»** открывает модальное окно со списком удаленных алгоритмов — можно выбрать нужные галочками и импортировать в один клик.
   - Кнопка **«Открыть сервер»** быстро открывает веб-сервис в браузере.
   - Кнопка **«Сброс»** мгновенно возвращает исходные 50 алгоритмов, если вы случайно что-то удалили или испортили.

## Как пользоваться

### Открытие панели управления
1. Нажмите `Ctrl + Shift + P` (или `Cmd + Shift + P` на macOS).
2. Введите команду:  
   `Algo Studio` (или `algoHelper.openManager`).
3. Справа откроется окно со всеми доступными алгоритмами, строкой поиска и кнопками управления.

### Добавление своего алгоритма
1. В шапке панели нажмите **«Новый алгоритм»**.
2. Укажите название, язык, категорию, сложность (например, `O(N)`) и вставьте код.
3. По желанию выберите картинку со схемой.
4. Нажмите **«Сохранить»** — алгоритм сразу появится в поиске и в автодополнении редактора.

## Быстрый старт для разработчиков

### Требования
- VS Code 1.75.0 или новее
- Node.js 16+ и npm

### Запуск и отладка
1. Склонируйте репозиторий и перейдите в папку проекта:
   ```bash
   git clone https://github.com/ValademerRTS/Algo-Studio.git
   cd algo-agent
   ```
2. Установите зависимости (если требуется):
   ```bash
   npm install
   ```
3. Откройте проект в VS Code:
   ```bash
   code .
   ```
4. Нажмите клавишу **`F5`**. Откроется новое окно VS Code (*Extension Development Host*) с запущенным расширением.
5. Для пересборки расширения в `.vsix` файл используйте:
   ```bash
   npx @vscode/vsce package
   ```
