# Algo Studio

Расширение для Visual Studio Code, объединяющее базу алгоритмических сниппетов для автодополнения и простой графический менеджер управления записями.

## Возможности

- Автодополнение готовых алгоритмов в редакторе кода (C++, C, Python).
- Графический менеджер для добавления, редактирования и удаления алгоритмов.
- Поиск по названию, сложности, категории и описанию в реальном времени.
- Фильтрация алгоритмов по языку программирования.
- Сохранение блок-схем и иллюстраций к алгоритмам.
- Копирование исходного кода в буфер обмена одной кнопкой.
