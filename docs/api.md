# Документация Algo Studio

Техническое руководство по структуре, функционалу и компонентам расширения Algo Studio для Visual Studio Code.

---

## 1. Описание проекта

Algo Studio — расширение для Visual Studio Code, объединяющее базу алгоритмических сниппетов и локальный менеджер управления записями. 

Расширение выполняет две задачи:
- Предоставляет быстрый доступ к шаблонам кода через стандартное автодополнение редактора.
- Позволяет просматривать, искать, редактировать и добавлять собственные алгоритмы через графическую панель.

Все данные хранятся локально в `context.globalState` редактора и сохраняются между сессиями.

---

## 2. Файловая структура

- `extension.js` — точка входа расширения. Содержит логику активации, регистрацию провайдера автодополнения, обработчики команд, генерацию HTML для Webview и логику синхронизации данных.
- `package.json` — конфигурационный манифест расширения. Описывает команды, поддерживаемые языки и события активации.
- `README.md` — базовая инструкция для конечного пользователя.
- `docs/documentation.md` — техническая документация проекта.

## 3. Функциональные модули

### Автодополнение (IntelliSense)
Реализовано с помощью `vscode.languages.registerCompletionItemProvider`.
- Поддерживаемые языки: C++, C, Python
- При наборе текста в редакторе проверяются совпадения с полем `name` каждого сохраненного алгоритма
- В выпадающий список подсказок выводится название, язык и сложность алгоритма, а при выборе вставляется готовый блок кода из поля `code`

### Графический менеджер (Webview)
Создается командой `algoHelper.openManager` через метод `vscode.window.createWebviewPanel`
- Интерфейс открывается во второй колонке редактора рядом с активным файлом
- Стили интерфейса используют системные CSS-переменные темы VS Code (`--vscode-*`), обеспечивая корректное отображение в темных, светлых и высококонтрастных темах
- Поддерживается добавление изображений и блок-схем: файл с диска конвертируется через `FileReader` в строку Base64 и сохраняется вместе с алгоритмом

### Поиск и фильтрация
Выполняется на стороне клиента (внутри скрипта Webview) без повторных обращений к API расширения:
- Поле текстового поиска выполняет регистронезависимый поиск по полям `name`, `description`, `complexity` и `category`
- Выпадающий список языков отсекает алгоритмы по полю `lang`

## 4. Модель данных

Каждая запись алгоритма хранится в массиве по следующей схеме:

| Поле | Тип | Описание |
|---|---|---|
| `id` | `string` | Уникальный строковый идентификатор записи |
| `name` | `string` | Название алгоритма и ключевое слово для автодополнения |
| `lang` | `string` | Язык программирования (`cpp`, `c`, `python`, `java`, `javascript`) |
| `complexity` | `string` | Оценка сложности алгоритма (например, `O(N log N)`) |
| `category` | `string` | Категория (например, `Сортировка`, `Поиск`, `Графы`) |
| `description` | `string` | Краткое текстовое пояснение работы алгоритма |
| `code` | `string` | Исходный код реализации |
| `image` | `string` | Изображение в формате Base64 Data URL (или пустая строка) |

## 5. Протокол взаимодействия (IPC)

Обмен данными между Webview и расширением происходит асинхронно через события `postMessage`

### Команды от Webview к расширению:
- `save` — передает объект `{ algo }` для добавления новой записи или перезаписи существующей по `id`
- `delete` — передает `{ id }` для удаления записи из базы данных
- `copy` — передает `{ code }` для записи текста в буфер обмена операционной системы через `vscode.env.clipboard.writeText`
- `reset_defaults` — заменяет текущий список алгоритмов на первоначальный массив по умолчанию

### Команды от расширения к Webview:
- `load` — передает актуальный массив `{ data }` для обновления списка карточек в интерфейсе

## 6. Разработка и сборка

### Локальная отладка:
1. Открыть папку проекта в VS Code
2. Нажать клавишу `F5` для запуска отладочного экземпляра Extension Development Host
3. Открыть любой файл `.cpp`, `.c` или `.py` для проверки автодополнения либо вызвать команду `algoHelper.openManager` через палитру (`Ctrl+Shift+P`)

### Сборка VSIX пакета:
1. Установить инструмент сборки:
   ```bash
   npm install -g @vscode/vsce
   ```
2. Собрать установочный пакет:
   ```bash
   vsce package
   ```
3. Установить полученный файл через интерфейс VS Code (`Extensions -> ... -> Install from VSIX...`) или через терминал:
   ```bash
   code --install-extension algo-studio-1.0.0.vsix
   ```
