## История коммитов

| Коммит | Сообщение | Реализованный функционал |
|---|---|---|
| 1 | `add algorithm dataset` | Базовый массив алгоритмов, регистрация провайдера автодополнения для C++, C и Python, персистентность в `globalState` |
| 2 | `implement webview manager` | Создание панели Webview, обработка команд `save`, `delete`, `copy`, `reset_defaults`, конвертация картинок в Base64 |
| 3 | `add real-time search, language filters, and category fields` | Живой поиск по строке запроса, фильтрация по языкам, поддержка полей категории и сложности, нативные стили VS Code |
